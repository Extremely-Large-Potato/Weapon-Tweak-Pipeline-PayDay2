Weapon Tweak Pipeline — User Guide
PAYDAY 2 Weapon Stat Modding Tool

Weapon Tweak Pipeline is a local tool for creating custom weapon-stat mods for PAYDAY 2. Choose your weapons, adjust stats via an intuitive UI, validate configurations, and export a ready-to-install SuperBLT mod package.

No Lua coding required.

============================================================
1. Running the Program
============================================================

Make sure your files look like this:

Weapon Tweak Pipeline/
│
├── WeaponLauncher.exe
│
└── Weapon Tweak Pipeline/
    ├── index.html
    ├── js/
    ├── data/
    ├── assets/
    └── libs/

Then simply double-click WeaponLauncher.exe.

The native C# launcher will:
- Bind to an available local loopback port automatically.
- Start an internal, zero-footprint HTTP server.
- Open the dashboard in your default browser.
- Run 100% locally on your machine with zero external dependencies.
- Automatically shut down when the browser tab is closed.

Important:
Do not move WeaponLauncher.exe inside the Weapon Tweak Pipeline folder.
The executable must stay next to the folder:

WeaponLauncher.exe
Weapon Tweak Pipeline/

If the launcher cannot find the folder, it will display a native Windows dialog box.

============================================================
2. Interface Overview
============================================================

The application is divided into three main sections:

Column 1: Find a Weapon
Use the search box to filter by:
- Weapon display name (e.g., Akron HC)
- Internal weapon ID (e.g., hcar)

Select a weapon to view its current base stats extracted directly from the game's data files.

Column 2: Properties & Operations
Select the properties you want to modify, choose an operation, and enter the desired value.
You can modify multiple properties on the same weapon.
When finished, click:
"Save this weapon's config"

Column 3: Validator, Code & Export
This section provides:
- Live validation feedback
- Real-time generated Lua code preview
- Real-time generated mod.txt preview
- One-click ZIP exporter

============================================================
3. The Three Operations
============================================================

Operation   What it does                           Example
----------------------------------------------------------------------
SET         Replaces the value completely          SET 60 on 30 -> 60
ADD         Adds (or subtracts with negatives)     ADD 10 on 30 -> 40
MULTIPLY    Multiplies the current base value      MULTIPLY 1.5 on 40 -> 60

SET:
Completely replaces the existing value.
Current: 30
SET 60 -> Result: 60

ADD:
Adds your value to the existing value.
Current: 30
ADD 10 -> Result: 40
(Use negative numbers to subtract: ADD -10 on 30 -> Result: 20)

MULTIPLY:
Scales the current value by a factor.
Current: 30
MULTIPLY 2 -> Result: 60
MULTIPLY 0.5 -> Result: 15

============================================================
4. Weapon Properties Explained
============================================================

Ammo Pickup Rate (Min / Max):
Controls how much ammunition is recovered per ammo box dropped by enemies.
- Ammo Pickup Min (Per Box): Guaranteed minimum rounds recovered.
- Ammo Pickup Max (Per Box): Maximum possible rounds recovered.
Note: Min must not be greater than Max. Safe cap is set to prevent balance exploits or engine crashes.

Magazine Size:
Controls how many rounds fit into the magazine before reloading.
Changing magazine size automatically scales total carried ammunition (AMMO_MAX) to maintain ammo reserve balance.

Fire Rate:
Measured in seconds between shots (delay cycle), NOT RPM.
Lower = Faster firing speed.
- 0.10s ≈ 600 RPM
- 0.07s ≈ 857 RPM
- 0.05s ≈ 1200 RPM
For fully automatic weapons, the tool automatically synchronizes the automatic-fire table.

Damage:
The Blackmarket UI displays calculated values rather than raw table data.
ADD is strongly recommended instead of SET for predictable results.
The validator will display a warning if SET is used on damage.

Reload Times:
- Reload: Mag Not Empty: Tactical reload with ammo still in the magazine.
- Reload: Mag Empty: Full reload timer when empty.
Both values are measured in seconds.
Lower = Faster reload.

Stability:
Controls handling, weapon kick, and recoil recovery.
Higher = Better (Less recoil kick and easier to control).
To improve stability:
- Use ADD with a positive value (e.g., ADD 4)
- Or use MULTIPLY above 1.0

Accuracy:
Controls bullet spread and shot grouping tightness.
Higher = Better (Tighter bullet spread / laser-like accuracy).
Negative adjustments (e.g., ADD -4) will widen shot spread.
To improve accuracy:
- Use ADD with a positive value (e.g., ADD 4)
- Or use SET to a higher value

Concealment:
Controls weapon detection risk.
Higher = Better (Lower detection risk).

Alert Size:
Controls sound radius when firing unsuppressed.
Lower = Better (Smaller detection bubble).

Suppression:
Controls how strongly shots cause enemy panic and flinch reactions.
Higher = Better.

Custom / Advanced Stats:
Allows direct manipulation of unlisted Lua paths (e.g., stats.zoom).
Ensure field names are exact; unverified custom paths are not checked against the game database.

5. Configuring Multiple Weapons
============================================================

You can configure and bundle multiple weapons into a single mod package:

AK5
 ├── Damage +20
 ├── Magazine +10
 └── Reload -0.5s

Akron HC
 ├── Damage +30
 └── Fire Rate ×0.8

AMR-16
 ├── Ammo Pickup Min = 2
 └── Ammo Pickup Max = 5

After setting up a weapon, click "Save this weapon's config". Select another weapon and repeat. All configurations will be combined into the final export.

============================================================
6. Validator & Error Handling
============================================================

Red Errors:
Critical errors that prevent ZIP creation (e.g., Min Pickup higher than Max, non-numeric values, missing fields). Fix these before exporting.

Yellow Warnings:
Advisory notices that allow export but highlight potential balance or visual issues (e.g., using SET on Damage or unusually high pickup rates).

============================================================
7. Exporting Your Mod
============================================================

Step 1: Enter your Mod / Folder Name.
Step 2: Enter the Author name.
Step 3: (Optional) Enter a Description.
Step 4: (Optional) Add a custom icon.png.
Step 5: Click "Build ZIP".

The generated archive contains:
Your Mod Name/
├── mod.txt
├── code.lua
└── icon.png (if provided)

============================================================
8. Installing in PAYDAY 2
============================================================

1. Extract the downloaded ZIP package.
2. Navigate to your PAYDAY 2 directory and locate the "mods" folder.
3. Place your extracted mod folder directly inside "mods":

PAYDAY 2/
└── mods/
    ├── base/
    └── Your Mod Name/
        ├── mod.txt
        ├── code.lua
        └── icon.png

4. Launch PAYDAY 2 and check Options > BLT Mods to verify your mod is loaded.
